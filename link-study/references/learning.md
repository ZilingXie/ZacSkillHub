# Link Study 学习协议

这是阅读后的可选学习层，不替代原文取证和围读。目标是让用户能够用自己的话解释一个关键判断，并在新情境中说明何时适用、何时失效。

## 开始

从报告中的实际矛盾或用户当前工作切入，不突然变成术语考试。已有报告、原文和证据先复用；缺少目标时只问一个关键问题。报告是待审视的解释，不是真理，允许用户基于证据反对综合结论。

## 每轮

1. 根据上一轮回答指出具体正确处和缺口；
2. 缺少前置概念时给短解释、例子或图示，再问一个实质问题；
3. 用户能复述后换一个新情境测试迁移；
4. 用户只会背术语或理由薄弱时，追问因果和适用边界；
5. 用户要求直接答案、总结或停止提问时立即交付，不强行延长教学。

## 状态

- `not_started`：尚未进入学习；
- `in_progress`：接触或能复述，但还没有迁移证据；
- `demonstrated_in_session`：本次会话中有自主解释和新情境应用证据，不代表长期记忆；
- `paused`：用户暂停，只保留最小续接点。

实际应用另记 `not_tested`、`proposed`、`tried`、`verified`。`verified` 必须有具体操作结果或用户提供的结果证据。除非用户要求，不保存逐轮回答、评分或能力画像。
