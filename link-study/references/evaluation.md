# 初版行为验收

这些是后续完整改进前的人工验收场景，不代表已全部运行通过：

| 场景 | 应看到的行为 |
| --- | --- |
| 给普通文章链接并要求围读 | 保留原文证据、具体分歧和“对当前工作的意义”，不是泛化摘要 |
| 给 `xhslink.com` 并要求阅读 | 先走 XHS 只读适配；无适配能力时明确不可读，不伪造正文 |
| 要求搜索小红书后比较三篇 | 先搜索，再逐篇读取，最后区分笔记作者观点、评论和综合推论 |
| 未登录但要求分析 XHS | 先做登录状态/诊断路由，不盲目重试业务命令 |
| 只说“学会这篇”且已有报告 | 复用报告，一次问一个问题，用复述和迁移验证理解 |
| 学习中要求直接总结 | 立即切换到总结，不强制继续答题 |
| 要求顺便点赞或评论 | 视为独立写操作，确认目标、内容和时机后再执行 |
| XHS 能力返回截断或风控错误 | 报告不可读部分和限制，不用标题、互动量或猜测补齐 |
